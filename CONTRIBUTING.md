# Contributing

Thanks for your interest. ikigai is pre-1.0 and in active use: APIs can change in a minor release, and do.

- Open an issue before a PR that changes a public API, adds a dependency, or spans more than one
  crate. Typo fixes, doc corrections and self-contained bug fixes can go straight to a PR.
- Contributions are accepted under the project's MIT OR Apache-2.0 dual license.
